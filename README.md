# DTGH_SSW

## Dense Tukey-Weighted Gradient Histogram and Structural Saliency Weight for Robust Optical-to-SAR Image Registration

**Semi-open-source MATLAB implementation of DTGH_SSW: An area-based optical-to-SAR image matching framework.**

This repository provides the MATLAB implementation of the proposed area-based optical-to-SAR image matching algorithm.

The source code and experimental data are being organized and standardized. The complete release will be updated after the official publication of the corresponding paper.

本项目提供一种基于区域的光学-SAR图像匹配算法 DTGH_SSW 的 MATLAB 实现。

相关代码与实验数据正在整理与规范化中，并将在论文正式发表后持续更新。


---

# Paper Information / 论文信息

**Title:**

Robust Optical-to-SAR Image Registration via Dense Tukey-Weighted Gradient Histogram and Structural Saliency Weight

**Authors:**

Wenhao Tong, Anxi Yu, Huatao Yu, Chenshuo Ma, Ziyu Yan, and Zhen Dong

**Status:**

Accepted for publication in  
*IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing (J-STARS).*


**Abstract:**

This work proposes a robust area-based optical-to-SAR image registration framework by integrating a Dense Tukey-weighted Gradient Histogram (DTGH) descriptor with a Structural Saliency Weight (SSW) mechanism.

本工作提出了一种鲁棒的光学-SAR图像配准框架，通过结合 Dense Tukey-weighted Gradient Histogram (DTGH) 描述子和 Structural Saliency Weight (SSW) 机制，实现复杂条件下的跨模态图像匹配。

# Semi-Open-Source Statement / 半开源声明

To protect the intellectual property of the proposed algorithm while maintaining reproducibility, the core computational modules are distributed as precompiled MEX binaries generated by MATLAB Coder.

为了保护算法核心知识产权，同时保证实验结果的可复现性，本文核心计算模块通过 MATLAB Coder 编译为预生成 MEX 二进制文件进行发布。
